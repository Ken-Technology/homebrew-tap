# Kenso Homebrew tap

The Homebrew formula for `kenso`, the command line for [Kenso](https://ken.so).

```sh
brew install ken-technology/tap/kenso
kenso --version
```

Update with `brew upgrade kenso`.

The formula installs the standalone build: the CLI with its own Node.js, so your machine needs no Node. It runs on macOS (Apple silicon and Intel) and Linux (arm64 and x64).

Docs and every other way to install: [ken.so/cli](https://ken.so/cli). Questions: contact@ken.so.

Each Kenso CLI release replaces `Formula/kenso.rb`, so an edit made by hand is overwritten.
